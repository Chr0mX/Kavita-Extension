Kavita for Paperback

A Paperback 0.9 extension that turns your Kavita server into a content source. Browse libraries, search, read and sync progress.

💡 Requires Paperback 0.9. This extension does not work on 0.8, the version from the App Store.

📲 How do I install it?
  1. Open this page on your iPhone or iPad, or go to Settings → Extensions → Add Repository in Paperback.
  2. Tap Add to Paperback above, or paste the repo URL (use Copy URL).
  3. Install the Kavita extension from the list.
  4. Open the extension settings, enter your Server URL, Username and Password, then tap Log In / Test Connection.

Want to try it first? Use the public demo server https://demo.kavitareader.com with username demouser and password Demouser64.

Features

  • 🔑Simple loginUsername and password. No API key to copy by hand.
  • 🌟DiscoverOn Deck, Recently Updated, Newly Added and one section per library.
  • 🔍SearchTitle search plus filters for genres, tags and people.
  • 📚Series & chaptersMetadata, cover art, and volume and chapter browsing.
  • 🔄Progress syncReading progress and per-series rating or review.
  • 🙈Your choiceOptional recursive search; hide book and novel libraries.
